# offline-transit-bcn

100% offline public-transport navigation for Barcelona (MVP). Android, Kotlin. No network needed at runtime: map, schedules and routing are all on the phone.

Status: scaffold. See `NOTICE.md` for data licences/attribution (OpenStreetMap ODbL, transport open data).
Code: Apache-2.0 (see LICENSE). Data packs are built by scripts in `data/` and are not committed.
